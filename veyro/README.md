# VEYRO

VEYRO is an AI-powered platform for creating simple Android apps and 2D games.

## V1 goals

- Clean mobile UI
- Create App / Create Game
- AI orchestration layer
- Automated testing and bug fixing
- Live preview
- APK/AAB build pipeline
- Free/Pro architecture
- 70-language-ready localization architecture

## Current status

Phase 1: Flutter UI foundation.

The code in this directory is intentionally isolated from the existing repository application until the VEYRO prototype is validated.
